This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Welcome to Geeked!
 
Geeked is my own personal blog that I made from scratch using the tutorial. I've added some quality of life improvements like better UI, error messages (not completely done) and removed the about page because I had nothing to write on it.

## Stuff I did for this project:

* Re-used CSS from my personal site at thegeekachu.github.io
* Used MongoDB for the first time, will use in the future, two thumbs up!
* Used React instead of React Native for the first time.
* Used Next.js for the first time, and it's usability was a pleasant surprise. Also will use again
* Did a lot of debugging and asking AI what I did wrong. Although it wrote no code, I would never have gotten past all those errors without it
* Better Auth was a bit fiddly, but not as much as Supabase Auth, so will use again as well
* Used npm instead of npx, I honestly don't know the difference,

## How to fork and make your own blog:

First, fork the repo, download, go into the root folder, and then run:
'''
npm run dev
'''
From there, you can use the Hack Club tutorial or your own expertise as needed to change styles, UI, and fix some bugs I was too lazy to.
Have a good time, and keep following the creature trail! (Wild Kratts reference.)
